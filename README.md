# Repositorio con el trabajo en Express

En este proyecto se hizo uso de Prisma con Express para administrar una base de datos en Supabase.

Para iniciar el servidor Express se usa:

```bash
npm run start
```

Para crear o consultar datos en las tablas se debe usar insomnia con las rutas:

```bash
http://localhost:3000/users/
http://localhost:3000/users/:id
http://localhost:3000/tasks/
http://localhost:3000/tasks/user/:userId
```
